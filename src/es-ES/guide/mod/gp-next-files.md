# Archivos y copias de seguridad

Usa **Mods → Abrir carpeta** para localizar los datos de esta edición. Standard y Lite pueden usar carpetas distintas.

Importa nuevos mods desde ZIP o carpeta. Los mods antiguos de `packs/` se incorporan siguiendo el aviso de migración. `patches/` contiene parches sueltos, `__gpn_edits/` ediciones manuales, `mod-data/` datos propios de los mods y `save-backups/` copias locales.

Cambia el orden y la activación desde el juego, no editando los registros de instalación. Los cambios posteriores pueden sobrescribir el mismo campo; las ediciones manuales también pueden tener prioridad.

Cierra el juego antes de copiar su carpeta de datos. Exportar un guardado o usar la nube no incluye automáticamente los datos propios de todos los mods. Conserva también `mod-data/` y la configuración correspondiente.
