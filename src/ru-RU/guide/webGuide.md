## Локальный запуск

Установите Git, версию Node.js, совместимую с зависимостями, и версию pnpm из `package.json`. Сделайте fork [репозитория сайта](https://github.com/Gzh0821/pvzg_site) и замените `YOUR_USERNAME` своим именем GitHub:

```bash
git clone https://github.com/YOUR_USERNAME/pvzg_site.git
cd pvzg_site
pnpm install
pnpm docs:dev
```

Откройте адрес предпросмотра из терминала. После правок выполните `pnpm docs:build` и проверьте результат.

## Где редактировать

| Содержимое | Каталог |
| --- | --- |
| Китайские страницы | `src/` |
| Английский, испанский, русский | `src/en/`, `src/es-ES/`, `src/ru-RU/` |
| Интерактивные инструменты | `src/components/` |
| Загрузки, изображения и общие JSON | `src/.vuepress/public/` |
| Навигация и стили | `src/.vuepress/` |

Страницы используют Markdown и frontmatter для заголовка, значка и порядка. Сохраняйте существующую конфигурацию, используйте относительные ссылки и обновляйте связанные переводы. Не редактируйте сгенерированные файлы в `.cache`, `.temp` и `dist`.

## Вклад в проект

Работайте в своей ветке и создайте Pull Request с описанием изменений и проверки. Ошибки и предложения можно отправлять в [Issues](https://github.com/Gzh0821/pvzg_site/issues), добавив шаги воспроизведения и снимки экрана.
