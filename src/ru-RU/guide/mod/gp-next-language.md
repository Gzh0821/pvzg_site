Создайте `jsons/lang/lang.json` или `.json5` в пакете. Используйте ключи исходной языковой таблицы и укажите заменяемые языковые поля.

```json
{
  "_languages": [{ "code": "es", "name": "Español", "isCJK": false }],
  "LoadingTips": [{
    "en": "Sun is your core resource.",
    "zh": "阳光是你的核心资源。",
    "es": "El sol es tu recurso principal."
  }]
}
```

`_languages` добавляет языки: `code` — код, `name` — имя в настройках игры, `isCJK` — правило ширины текста. Для изменения существующих языков поле можно не указывать.

Объекты объединяются рекурсивно, массивы заменяются. Пример заменяет список `LoadingTips`; включите остальные подсказки, которые хотите сохранить. Названия и тексты альманаха также меняются в соответствующих патчах Features и Almanac.

[Установите и примените](./gp-next.md) пакет, затем переключите язык в настройках игры. Язык панели GP-Next задаётся отдельно. Ключи и исходные тексты доступны в [данных игры](./gp-next-json.md).
