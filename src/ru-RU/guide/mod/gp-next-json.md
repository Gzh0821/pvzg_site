## Загрузка исходных данных

[Архив JSON игры 0.15.0](/resources/game-json-0.15.0.zip) содержит Features, Objects, уровни и языковые данные. Источники и контрольные суммы указаны в `MANIFEST.json`. Это справочные данные, а не готовый мод.

## Экспорт из игры

В Данных GP-Next выберите тип и экспортируйте исходные или текущие данные. Исходные нужны как образец для патча; текущие включают изменения модов и помогают искать конфликты.

Можно использовать [консоль](./gp-next-console.md). Команды экспортируют исходные свойства растений, текущие свойства и исходную языковую таблицу:

```js
await gpNext.exportJson('PlantProps', true)
await gpNext.exportJson('PlantProps')
await gpNext.exportLang(true)
```

В `exportJson(type, useOriginal, autoDownload)` последние параметры по умолчанию равны `false` и `true`. Отключите `autoDownload`, чтобы получить данные без окна сохранения.

| Содержимое | Тип |
| --- | --- |
| Имена, порядок, ресурсы карточек | `Features` |
| Здоровье, урон, стоимость, перезарядка | `Props` |
| Тексты альманаха | `Almanac` |
| Магазин | `StoreCommodityFeatures` |
| Общий интерфейс | Языковая таблица |

Далее используйте [структуру пакета](./gp-next-datapack.md) и [правила объединения](./gp-next-merge.md).
