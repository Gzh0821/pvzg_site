# Настройки

В настройках меняются язык панели, клавиша F9 и прокрутка. Язык самой игры выбирается отдельно в её настройках.

Ограничение FPS находится в **Производительности**. Отображение здоровья растений, зомби и могил — в **Инструментах**. Две строки могут обозначать здоровье и броню.

Для параметров мода откройте его карточку, сохраните изменения и примените или перезапустите игру по подсказке. Экспериментальные функции включайте по требованиям мода. JavaScript включается только через консоль. Справка открывает сайт.
