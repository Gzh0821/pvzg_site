# Файлы и резервные копии

Откройте папку данных через вкладку модов. Standard и Lite могут использовать разные папки.

Устанавливайте новые моды импортом ZIP или папки. Старые моды из `packs/` переносятся по подсказке. `patches/` содержит отдельные патчи, `__gpn_edits/` — ручные изменения, `mod-data/` — данные модов, `save-backups/` — локальные резервные копии.

Меняйте порядок и включение через игру, а не вручную в записях установки. Поздние изменения одного поля могут перекрывать ранние; ручные изменения тоже могут иметь приоритет.

Перед копированием папки закройте игру. Экспорт игрового сохранения и облако не включают автоматически все данные модов. Сохраняйте также `mod-data/` и соответствующую конфигурацию.
