[Gardenest](https://nest.pvzge.com/) — платформа сообщества PvZ2 Gardendless для уровней, пакетов данных, модов и инструментов/плагинов. **Сейчас она проходит Beta-тестирование.**

## Поиск и загрузка

Общедоступные работы можно просматривать без входа. В разделе [Поиск](https://nest.pvzge.com/discover) доступны фильтры по типу, словам и совместимости. По умолчанию выбран рекомендованный порядок; его можно изменить. Страница проекта содержит описание, авторов, зависимости и версии.

Во вкладке загрузок выберите локальную версию и проверьте совместимость, обязательные и необязательные зависимости. Для внешних версий используйте ссылки автора. Инструменты/плагины используйте по инструкции автора; это не моды GP-Next. Публикация и базовые проверки не означают успешную проверку антивирусом или тест в игре; смотрите указанный статус.

| Файл | Использование вручную |
| --- | --- |
| Уровень JSON/JSON5 | Загрузить по [руководству уровней](./level/) |
| ZIP пакета данных/мода | Импортировать в [GP-Next](./mod/gp-next.md), выбрать включение и применить |
| ZIP уровня или инструмент/плагин | Следовать структуре пакета и инструкции автора |

### Играть / Импортировать в игру

Настольный клиент с поддержкой протокола Nest можно открыть из раздела загрузок. Уровни JSON/JSON5 проверяются и запускаются напрямую. ZIP пакетов данных/модов импортируются после подтверждения в игре и остаются выключенными, без автоматического применения. Обновления также остаются выключенными и не заменяют немедленно работающий контент. Проверки скриптов, доверия и зависимостей сохраняются.

ZIP уровней, инструменты/плагины и версии только с внешними ссылками не имеют этой кнопки. Интеграция проходит Beta-тестирование и требует совместимого клиента. Система может запросить открытие внешнего приложения; если клиент не запускается или версия не поддерживается, скачайте файл вручную.

## Вход и безопасность

Используйте способ, доступный на [странице входа](https://nest.pvzge.com/login). Новые пользователи создают аккаунт по указанной процедуре; при соблюдении правил подтверждённой почты возможна привязка к существующему аккаунту. Другие платформы привязывайте в настройках существующего аккаунта. В разделе безопасности доступны ключи доступа, приложение-аутентификатор, двухфакторная аутентификация и коды восстановления. Для администраторов двухфакторная аутентификация обязательна.

Никнейм и имя пользователя независимы. Обычные аккаунты по умолчанию используют публичный UID; проверенные разработчики и более высокие роли могут выбрать допустимое уникальное имя. Профиль показывает работы, уровень и публичные данные; видимость избранного настраивает сам пользователь.

## Создание и публикация

1. Войдите и откройте [Центр творчества](https://nest.pvzge.com/author) через меню аккаунта. Нажмите Новый проект справа вверху.
2. Укажите название, тип, видимость, краткое описание и текст Markdown. Зависимости необязательны: найдите проект по ID или добавьте краткую информацию, если совпадения нет.
3. Загрузите версию. Уровни принимают JSON/JSON5 или ZIP; пакеты данных и моды — ZIP по правилам GP-Next. Инструменты/плагины используют ZIP без обязательного GP-манифеста или UUID.
4. Укажите версию и совместимость, отправьте и проверьте результаты. Изменения обычных пользователей проходят модерацию; проверенные разработчики и более высокие роли при соблюдении правил могут публиковать без ручной проверки. Проверки файлов, квот и архивов сохраняются.

Команда и приглашения управляются в Центре творчества. В настройках квот можно посмотреть лимиты места, ежедневных загрузок и проектов. Старые версии и загрузки команды учитываются для соответствующего аккаунта; место удалённых файлов освобождается после завершения очистки.

## Задания и уведомления

[Центр заданий](https://nest.pvzge.com/tasks) показывает уровень, опыт, ежедневные отметки и задания. Даты считаются по времени Гонконга; время обновления показывается в вашем часовом поясе. Прочитанные [уведомления](https://nest.pvzge.com/notifications) можно удалить только для своего аккаунта, не меняя состояние других пользователей. Новости доступны в [объявлениях](https://nest.pvzge.com/announcements).

Во время Beta сообщайте об ошибках через [обратную связь](../contribution/feedback.md), приложив шаги, ID проекта/версии и доступные для публикации ошибки. Не отправляйте пароли, коды восстановления или данные входа.
