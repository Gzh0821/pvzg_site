1. 从[创意花园](../../creator-garden/)取得关卡 JSON，检查作者要求的游戏版本和模组。
2. 打开游戏设置，选择 `Play Local Level`。
3. 选择关卡 JSON 并确认。若下载的是压缩包，先解压出关卡文件。

无法识别时检查文件是否完整、是否确实为关卡 JSON；进入后报错则核对版本和依赖，并保留错误信息。

制作关卡见[关卡指南](../level/)，植物与僵尸数据见[在线图鉴](../../almanac/)。
