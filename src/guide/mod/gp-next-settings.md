## 面板与输入

在“设置”里修改面板语言、打开面板的热键和滚动选项。默认热键为 **F9**。

- 面板语言只控制 GP-Next 界面；游戏文字语言在游戏自己的设置里选择。
- 连续滚动灵敏度控制列表滚动速度。
- 离散选择间隔用于减少世界选择、沙盒卡片等位置的连续跳选；触控板容易跳过目标时可适当增加。

## 帧率与血量

帧率只在“实验性”里设置：开启实验性调度后选择目标帧率，初始值为 120 FPS；关闭后由游戏本体控制。性能页只读，显示引擎实际帧间隔的统计值，可能与目标值不同。

血量显示在“工具”里设置，可分别显示植物、僵尸和墓碑。带护甲的对象可能显示两行血量。

## 模组设置

进入“模组”，点模组名称，再修改它提供的选项。保存后按界面提示应用；需要重启时，先结束当前游玩。模组没有提供设置时，不会出现设置项。

## 实验性功能

地图和植物等级等选项按模组要求开启；实验性帧率调度可按需要单独开启。改变影响存档的功能前先备份。JavaScript 模组默认关闭；在“实验性 → JS Modding”阅读一次风险说明并确认后开启，无需控制台。关闭后按提示重启，JS 模组及依赖它们的包暂停加载，原启用选择保留；重新开启时仍须通过正常检查。纯 JSON 包无需开启，除非它依赖 JS 前置。

## 偏好导入与导出

在“设置”导出 GP-Next 偏好 JSON；导入后先核对预览，再应用并重启。包含语言、热键、滚动和血量显示等偏好，不包含游戏存档、模组启用配置、模组自身设置或实验选项。

[诊断与启动恢复](./gp-next-recovery.md)

顶部标签显示不全时，可用滚轮、触控板／触屏横向滑动，或按住鼠标左键拖动。拖动不会切换标签；选中标签会自动显露，并尽量露出相邻标签。也可用方向键及 Home/End 切换，不再提供下拉菜单。

## 脚本的权限边界

JS Modding 执行可信代码，不是隔离沙箱。模组与游戏共用页面，能接触页面存储及窗口获准的原生能力；不要运行来源不明的脚本。

当前 CSP（内容安全策略）限制页面可加载的脚本、资源和可连接的网络来源；它不妨碍已打包入口、包内资源和通过 API 调用前置逻辑。任意远程脚本和未获准的网络地址不能假定可用。Tauri 的默认文件读写范围收紧到 GP-Next 与补丁所需目录；文件对话框选择的导入／导出路径按对应操作授权。这些限制不是每个模组独立的权限隔离。

使用 `ctx.files` 读取自身或已声明的直接前置，使用 `ctx.storage` 保存模组数据。共享运行期逻辑用 `ctx.services`，启动逻辑用 `ctx.registry`；不要跨包拼文件路径做 ESM import，也不要绕过权限读取玩家文件。
