GP-Next 是游戏内的模组管理和辅助工具。按 **F9** 或点击左上角按钮打开侧栏，热键可在设置里修改。

| 页面 | 可以做什么 |
| --- | --- |
| 模组 | 导入、启用、停用和更新模组，调整顺序，修改模组设置 |
| 工具 | 修改器、血量显示和云存档；可用项目随当前场景变化 |
| 数据 | 查找数据、比较原始值和当前值、导出或手动修改 |
| 性能 | 查看实际帧率、采样和保存报告 |
| 诊断 | 模组错误、日志、诊断报告、重启 |
| 设置 | 面板语言、热键、滚动和常规选项，打开官网帮助 |
| 实验性 | 帧率调度、地图和植物等级等实验功能 |

## 安装模组

1. 下载模组 ZIP；不用解压，也不用安装编程工具。
2. 打开 **模组 → 导入 ZIP**，选择文件，核对名称和版本后安装。
3. 勾选模组，保存选择，再按提示应用。出现“重启并应用”时先结束当前游玩，再重启。
4. 点模组名称查看它提供的设置、操作或错误原因。

如果作者给的是文件夹，使用“导入文件夹”，选择包含 `pack.json` 的那一层。需要前置模组时一起安装，缺少前置会显示名称。

## 更新与停用

更新时重新导入新 ZIP。相同 `uuid` 会被识别为同一个模组的新版本；安装后仍需应用。

停用时取消勾选、保存并应用。含新植物、僵尸或资源的模组通常需要重启。不要在战斗中强行切换；若存档仍引用模组内容，按提示恢复所需模组。

修改作者原文件夹不会自动改变已安装版本，需要重新导入。首次发现旧 `packs/` 内容时，按迁移提示确认后使用新管理界面。

## JavaScript 模组

JavaScript 模组默认关闭；在“实验性 → JS Modding”阅读一次风险说明并确认后开启，无需控制台。关闭后按提示重启，JS 模组及依赖它们的包暂停加载，原启用选择保留；重新开启时仍须通过正常检查。纯 JSON 包无需开启，除非它依赖 JS 前置。

只安装可信来源的脚本。脚本包更新且内容发生变化时，需要重新确认信任；导入 ZIP 不会自动打开 JS Modding。

## 出现问题

- 缺少依赖：安装提示中的前置模组，检查其版本和启用状态。
- 应用后打不开游戏：使用恢复界面返回上次可用配置，不要反复清空存档。
- 数值不符合预期：检查模组顺序和“数据”里的手动修改。
- 向作者反馈：提供游戏版本、模组版本、复现步骤和相关日志。

## 依赖、更新与卸载

模组详情和导入预览会列出前置与必需功能的状态。缺少前置时先导入并启用它；内置功能未开启时，可从提示跳到对应设置，开启后重新尝试。未知功能 ID 应由作者修正，平台不会自动替你开启功能。GP-Next 版本范围不匹配只警告，与必需功能缺失不同。

含脚本的包需先开启 JS Modding 才能导入。脚本包更新且内容发生变化时会要求重新确认信任，不能只凭相同名称或版本号继承信任。当前支持 ZIP 和文件夹；RAR 请先解压，再导入文件夹。

在模组详情选择“卸载”并确认，再按提示应用或重启。仅通过新版管理器导入的模组提供卸载；旧目录迁移项不提供此操作。若其他已启用模组依赖它，须先处理这些依赖。卸载从配置中移除模组，不等于清空存档、模组自有数据或彻底删除磁盘快照；存档内容依赖仍须检查。

## 从创意苗圃获取作品

在[创意苗圃（Beta）](https://nest.pvzge.com/discover)浏览数据包和模组，在作品页的“下载”中选择版本，核对兼容性及必需／可选依赖，再下载 ZIP 按上面的步骤导入。苗圃也提供关卡与工具／插件；工具 ZIP 不作为 GP-Next 模组导入。

支持 Nest 协议的桌面客户端可使用“导入游戏”；导入的数据包和模组默认关闭，更新同一包也不会自动启用或应用。游戏仍会检查依赖及脚本信任。此入口仍在 Beta 联调，未安装支持版本或无法唤起时请手动下载。详见[苗圃使用指南](../gardenest.md)。
