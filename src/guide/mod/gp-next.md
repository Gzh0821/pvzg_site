# GP-Next

GP-Next 是游戏内的模组管理和辅助工具。按 **F9** 或点击左上角按钮打开侧栏，热键可在设置里修改。

| 页面 | 可以做什么 |
| --- | --- |
| 模组 | 导入、启用、停用和更新模组，调整顺序，修改模组设置 |
| 工具 | 修改器、血量显示和云存档；可用项目随当前场景变化 |
| 数据 | 查找数据、比较原始值和当前值、导出或手动修改 |
| 性能 | 设置目标帧率、查看实际帧率、采样和保存报告 |
| 日志 | 筛选和复制错误信息，排查模组问题 |
| 设置 | 面板语言、热键、滚动和常规选项，打开官网帮助 |
| 实验性 | 使用模组明确要求的实验功能 |

## 安装模组

1. 下载模组 ZIP；不用解压，也不用安装编程工具。
2. 打开 **模组 → 导入 ZIP**，选择文件，核对名称和版本后安装。
3. 勾选模组，保存选择，再按提示应用。出现“重启并应用”时先结束当前游玩，再重启。
4. 点模组名称查看它提供的设置、操作或错误原因。

如果作者给的是文件夹，使用“导入文件夹”，选择包含 `pack.json` 的那一层。需要前置模组时一起安装，缺少前置会显示名称。

## 更新与停用

更新时重新导入新 ZIP。相同 `uuid` 会被识别为同一个模组的新版本；安装后仍需应用。

停用时取消勾选、保存并应用。含新植物、僵尸或资源的模组通常需要重启。不要在战斗中强行切换；若存档仍引用模组内容，按提示恢复所需模组。

修改作者原文件夹不会自动改变已安装版本，需要重新导入。首次发现旧 `packs/` 内容时，按迁移提示确认后使用新管理界面。

## JavaScript 模组

纯 JSON 模组不需要开启 JavaScript。当前 JavaScript 模组只允许手动从开发者控制台启用，设置页不能打开它：

```js
await gpNext.mods.enableJsModding()
```

在游戏中按 F12 打开开发者工具，切换到 Console，执行后按提示应用或重启。JavaScript 模组能够执行代码，只安装可信来源。关闭方式见[控制台](./gp-next-console.md)。

## 出现问题

- 缺少依赖：安装提示中的前置模组，检查其版本和启用状态。
- 应用后打不开游戏：使用恢复界面返回上次可用配置，不要反复清空存档。
- 数值不符合预期：检查模组顺序和“数据”里的手动修改。
- 向作者反馈：提供游戏版本、模组版本、复现步骤和相关日志。
