# 安装位置与备份

在 **模组 → 打开目录** 查看当前游戏使用的数据目录。以游戏打开的位置为准，Standard 和 Lite 可能使用不同目录。

新模组使用“导入 ZIP”或“导入文件夹”安装。`packs/` 是已有模组的发现和迁移入口；不要直接编辑已安装文件来更新模组。

| 内容 | 作用 |
| --- | --- |
| `packs/` | 已有 ZIP 或文件夹模组，首次使用按提示迁移 |
| `patches/` | 散装 JSON 补丁，原有玩家仍可使用 |
| `__gpn_edits/` | 在“数据”里保存的手动修改 |
| `mod-data/` | 模组自己保存的进度或其他数据 |
| `save-backups/` | 模组操作相关的本地存档备份 |

不要手动改管理器保存的配置和安装记录。调整启用状态、顺序和设置时使用游戏界面。

## 哪个修改优先

普通模组按管理器中的顺序叠加，后加载的修改覆盖前面的同一字段；散装补丁和手动编辑可能继续覆盖它们。排查数值时同时检查“数据”中的手动修改。

还原手动编辑不会删除模组自带的修改。分享作品时，应整理成带 `pack.json` 的独立 ZIP，不要直接分享整个游戏数据目录。

## 备份和换电脑

先关闭游戏，再备份游戏数据目录。只导出原生存档不会自动包含所有模组自有数据；需要保留模组进度时，同时备份 `mod-data/` 和相关模组配置。云存档不等于整个模组目录同步。

恢复配置与恢复存档是两件事。选择恢复存档前核对时间和玩家，避免覆盖需要保留的进度。
