[创意苗圃 Gardenest](https://nest.pvzge.com/) 是 PvZ2 Gardendless 的社区作品平台，**目前处于 Beta 测试阶段**，支持关卡、数据包、模组和工具／插件。

## 浏览与下载

无需登录即可浏览公开作品。在[探索](https://nest.pvzge.com/discover)按类型、关键词和兼容性查找；默认按推荐排序，也可手动切换。作品页提供介绍、作者、依赖与版本信息。

在“下载 → 本地下载”选择版本，检查兼容性、必需依赖和可选依赖后下载。外链作品按作者提供的链接获取文件；工具／插件按作者说明使用，不作为 GP-Next 模组导入。发布和基础检查不代表病毒扫描或游戏内验证已经通过，请阅读作品上的检查状态。

| 文件 | 手动使用方式 |
| --- | --- |
| 关卡 JSON／JSON5 | 按[自定义关卡指南](./level/)载入游戏 |
| 数据包／模组 ZIP | 在[GP-Next](./mod/gp-next.md)的模组页导入，选择启用并应用 |
| 关卡 ZIP、工具／插件 | 按作者的包结构和使用说明处理 |

### 在游戏中游玩／导入游戏

支持 Nest 协议的桌面客户端可通过作品下载区唤起：关卡 JSON／JSON5 校验后直接游玩；数据包和模组 ZIP 经游戏确认后导入，默认关闭，不会自动应用。同一包更新也保持未启用，当前运行内容不会立即替换。脚本开关、信任和依赖检查仍然有效。

关卡 ZIP、工具／插件和仅外链版本不提供此入口。该联动仍在 Beta 联调，需要支持协议的客户端，系统可能提示打开外部应用；若无法唤起或版本不支持，请使用手动下载。

## 登录与账号

使用[登录页](https://nest.pvzge.com/login)提供的方式登录；首次第三方登录按页面流程建立账号。已有账号请在“设置 → 第三方账号”绑定其他平台，不要为同一身份重复建号。可在账号与安全中配置通行密钥、验证器、双重验证和恢复码；管理员强制使用双重验证。

昵称与用户名独立，普通账号默认用户名为公开 UID；认证开发者及以上可修改合法、唯一的用户名。个人主页可展示作品、等级与公开资料，收藏是否公开由本人设置。

## 创建与发布作品

1. 登录后进入账号菜单中的[创作中心](https://nest.pvzge.com/author)，点击右上角“新建项目”。
2. 填写名称、类型、可见度、简介和 Markdown 介绍；依赖可不填，也可用项目 ID 匹配，未匹配时补充简要信息。
3. 创建项目后上传版本：关卡接受 JSON／JSON5 或 ZIP；数据包和模组使用符合 GP-Next 规则的 ZIP；工具／插件使用 ZIP，不要求 GP 清单或 UUID。
4. 补充版本和兼容信息，提交后查看检查结果。普通用户的内容变更需审核，认证开发者及以上符合规则时免人工审核；文件校验、额度和归档检查仍会执行。

创作中心也管理团队与邀请。在“设置 → 额度管理”查看当前总空间、每日上传和项目数量额度；旧版本和团队上传也会计入相关账户，删除后的空间须等文件清理完成才释放。

## 任务与通知

在[任务中心](https://nest.pvzge.com/tasks)查看等级、经验、每日签到和成长任务；签到按香港日期结算，页面刷新时间按用户本地时区显示。[通知](https://nest.pvzge.com/notifications)集中展示消息，已读消息可自行删除，不改变其他用户的状态。公告在[公告页](https://nest.pvzge.com/announcements)查看。

Beta 期间若遇到问题，请附上操作步骤、项目或版本 ID，以及可公开的报错信息，通过[问题反馈](../contribution/feedback.md)提交；不要附带密码、恢复码或登录凭据。
