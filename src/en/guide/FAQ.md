## Download and update

Choose a platform and edition on the [download page](../download/); check [system requirements](./requirement.md). Export your save before updating and verify progress in the new version before removing the old package.

## How do I back up or transfer saves?

Select your player name in the main menu to export a save. Different platforms or packages may use different data directories, so do not assume automatic transfer. Keep mod-owned data separately; see [files and backups](./mod/gp-next-files.md).

## What if the game fails to start, crashes or runs slowly?

Check the package and system requirements first. If GP-Next opens recovery, follow [diagnostics and recovery](./mod/gp-next-recovery.md). If the game opens, use safe mode to isolate mod effects and export a report. Lag alone does not prove that a device is unsupported.

## How do I install or create mods?

Players can start with [using mods](./mod/gp-next.md); authors with [datapacks](./mod/gp-next-datapack.md) or [official examples](./mod/gp-next-examples.md). Find API and field references in the [documentation index](./mod/).

## How do I import a custom level?

Choose `Play Local Level` in game settings and open the level JSON. See the [level guide](./level/) for creating levels and the [Creator Garden](../creator-garden/) for community content.

## Where can I look up entities or edit saves?

Use the [Almanac](../almanac/) and [tools](../useful-tool/). Back up before editing and use a save exported by the current game version.
