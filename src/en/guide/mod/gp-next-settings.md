# Settings

Use Settings for the panel language, shortcut and scrolling. The default shortcut is F9. The game text language is selected in the game's own settings, independently of the panel language.

Continuous scrolling changes list speed. The discrete selection interval helps prevent trackpad input from skipping worlds or sandbox cards.

Set target FPS in **Performance**. Actual FPS can be lower; compare measurements in the same scene. Configure plant, zombie and tomb health display in **Tools**. An additional health line may represent armor or a shell.

Open a mod's details to change its settings, then apply or restart as prompted. Enable experimental map or plant-level options only when the mod requires them. JavaScript can only be enabled through the [console](./gp-next-console.md). Help opens the website.
