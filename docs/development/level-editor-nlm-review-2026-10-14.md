# 关卡编辑器：NLM 对照与 Nest 风格调整

2026-10-14。依据 NLM 在线 v1.3 页面及其源码、官网编辑器、当前本地游戏本体的 `levelController.ts` / `NPC_Controller.ts` 编译模块，以及 `docs/game-json-files/levels` 的 1311 个官方关卡。游戏数据标识为 v0.15.0；没有以版本号推定字段未变化，也没有验证未提供的更新包。

参考：[NLM 在线工具](https://osamah2004.github.io/nlm/)、[NLM 源码](https://github.com/Osamah2004/nlm)。Nest 样式依据社区仓库 `apps/web/app/assets/community.css` 的当前配色和玻璃材质变量。

## 功能差距与建议

| 优先级 | 功能 | 官网当前情况 | 建议 |
| --- | --- | --- | --- |
| 高 | 剧情对话 | 没有专门的可视化编辑入口 | 支持开场/重玩/结束引用、角色和 `NarrativeProperties.Flow` 动作序列；按游戏实际支持的动作提供选项 |
| 高 | 生成器波次 | 支持导入保留，缺少完整可视化构建入口 | 独立于静态波次；先支持官方模板和生成器参数，再提供升级波次规则，避免改动时意外改写为静态波次 |
| 高 | 卡组配置 | 已有选卡/固定卡组/包含/排除/卡槽覆盖 | 补充 `CardDecks.Recommended` / `Challenging` 的多套卡组配置，这是当前本体仍使用的逻辑 |
| 中 | 僵王关卡 | 没有专门面板 | 编辑 `ZombossBattleModuleProperties` 的僵王类型、生成位置、保留列及音乐；类型应来自当前游戏数据 |
| 中 | 空袭与飞船 | 没有专门面板 | 编队、`TargetPoint`、飞船属性分组编辑；必须使用本体实际处理的模块类名，不能凭 UI 名称猜 `AirRaidProperties` |
| 中 | 特殊小游戏 | 部分目标/规则已有，完整模式配置仍缺失 | 分批支持砸罐子、保龄球、炮击等模式；路径、罐子内容和模式参数按各自模块编辑 |
| 中 | 素材/僵尸快捷键 | 有搜索和分类，没有 NLM 的僵尸快捷键槽 | 优先提供可发现的键盘操作和快捷键帮助，不能抢占输入框的编辑快捷键 |
| 中 | 草稿恢复 | 只有高级模式偏好持久化，没有关卡草稿恢复 | 将整个草稿和原始导入快照一起保存，并提供明确恢复入口；NLM 分散保存表单项的方式不适合直接移植 |

官网已经有棋盘布置、轨道/潮水/能量瓷砖规则、保护植物等目标、波次复制和插入、事件动作、动态僵尸池、传送带及 JSON 预览。应完善入口和工作流程，而不是重复实现。

## 本次实现

- 沿用 Nest 的浅色青绿 / 深色薄荷配色、24px 面板圆角和系统字体层级。
- 浮动工具栏、棋盘操作栏、JSON 窗口和传送带属性抽屉使用不同厚度的玻璃材质。内部输入区保持清晰底色，避免多层透明影响阅读。
- 增加基础 / 棋盘 / 波次定位导航以及波次、布置数量；保留宽屏三栏和窄屏单列布局。
- 增加最多 50 个草稿状态的撤销/重做，支持 Cmd/Ctrl+Z、Shift+Cmd/Ctrl+Z。输入框保留原生撤销；导入和新建开始新的编辑历史。撤销恢复草稿，不回滚 ID 分配器，避免分支编辑产生重复 ID。
- 传送带抽屉改为无蒙层的并行属性面板；新建确认和 JSON 预览仍使用模态窗口。
- 修正旧 `.dark` 选择器为当前主题的 `data-theme="dark"`，并使用组件库支持的 `wrapClassName` 让模态窗口玻璃样式实际生效；薄荷色选中项使用深色文字保持对比度。
- 生产构建验证发现：手工将 WebKit 模糊属性写在标准属性后面，会让 CSS 压缩结果只留下前缀属性，Chrome 不识别。已移除手工前缀，交由构建工具按目标浏览器处理，并检查生产 CSS 及线上实际模糊效果。
- 保留减少动态效果，并补全减少透明度 / 高对比度下的实色材质。

## 游戏字段核对

本体 `module_SetWaveProperties` 使用的初始值为：`WaveSpendingPointIncrement=10`、`MinNextWaveHealthPercentage=0.5`、`MaxNextWaveHealthPercentage=0.65`。编辑器的新建和缺失字段默认值此前为 30 / 0.55 / 0.7，本次已对齐。导入显式值仍按原值保留。

以下语义已核对，不能按 NLM 的表单显示方式推断：

- `OverrideSeedSlotsCount` 在 chooser 分支只接受正数；当前编辑器的显式覆盖开关仍有效。
- 首波倒计时和上述波次点数/血量阈值在本体读取时采用真值判断，0 不会按字面应用。编辑器首波倒计时为 0 时输出 0.1 的处理保留；导入字段不被批量改写。
- `DynamicZombies` 由 `WaveManagerModuleProperties` 读取；静态和生成器波次要分别保留原始引用关系。不能假设 WaveManager 总是由同一个模块直接引用。
- 剧情引用在 `LevelDefinition` 的首次/重玩开场与结束字段上，并由 `NPC_Controller.Getflow` 解析 `NarrativeProperties.Flow`。
- `CardDecks` 仍由本体的 SeedBank chooser 分支读取，属于可添加的新编辑入口。

现有波次 round-trip 检查覆盖 1311 个关卡（1241 静态、70 生成器），14704 普通、344 风暴、28 地面僵尸条目；动态池、特殊引用和未解析对象按检查预期保留。VuePress 完整构建通过。独立 Chromium 浏览器验证了撤销/重做、分支编辑、快捷键，以及静态 / 生成器 / 其他三类实际关卡的导入→修改→撤销→原样导出。桌面 1440px、平板 820px、手机 390px 无页面横向溢出；四种语言分别检查了桌面和手机。实际深色主题、JSON / 确认弹窗、无蒙层传送带抽屉、减少动态效果和减少透明度均已检查。尚未在游戏中运行导出关卡；源码核对与序列化检查不能代替游戏实测。
