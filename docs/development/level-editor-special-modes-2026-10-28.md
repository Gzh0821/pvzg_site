# 关卡编辑器：僵王、空袭与飞船

2026-10-28，第六轮。继续沿用游戏字体标题、Gardenest 主工作区和磨砂玻璃。新增功能使用单层并行面板，不再套用折叠表单。

## 工作流

- 文件菜单直接新建僵王或空袭关卡。提供 36 种僵王的原生关卡、4 个原生空袭关卡，按需加载完整模板，保留舞台、卡槽、波次、胜负条件及本关类型 / 属性依赖，只替换名称与描述。
- 导入或新建后，主导航下出现对应的僵王 / 空袭 / 飞船快捷入口，从任何工作区可直接打开设置。设置面板无蒙层，可以保留棋盘或波次上下文。
- 僵王直接编辑类型、出生行列、右侧保留列及入场音乐。棋盘用现有游戏卡图标出生点，变化即时反映；没有另造占位图片。
- 空袭最多三支编队，可添加、删除、排序，分别编辑名称语言和难度；升级阶段平铺植物和分数，桌面只显示一次列标题，手机按行堆叠字段。支持本关植物类型和当前游戏的 233 种全局植物类型，当前未知值保留。
- 飞船编辑生命、护盾生命、三叶草速度 / 伤害、甲板边界及护盾策略。共享配置先显示实际值，再显式复制为本关配置；不修改共享对象。缺失字段显示本体默认值，不因打开面板而写入默认字段。
- 复制配置时避开已有别名，替换对应 RTID，保留模块顺序及重复引用。移除玩法只解除对应引用，原始对象保留，支持撤销。
- 当前模块、编队与名称语言随工程保存。修改、撤销重做、工程导入和刷新恢复保留上下文与原始导入快照。

## 0.16.1 语义

依据原版 `levelController.ts`、`AirRaidTeamChooser.ts`、`ZombossMechZombie.ts`、`SkyZombossMechZombie.ts` 及原生关卡资源。

- 僵王实际读取 `ZombossBattleModuleProperties`；空袭实际读取 `SkyMiniGameProperties`；飞船实际读取 `SkyCityShipProperties`，没有猜造 `AirRaidProperties`。
- 僵王的保留列从右往左锁定。出生位置为本体 0 起始格坐标，界面统一显示为 1 起始行列；保留对象里的位置扩展字段。
- `DiscardBossMusic` 优先于 `UseKongfuBossMusic`，对应保留关卡音乐 / 功夫入场 / 普通僵王入场三个选项。原 JSON 的 `ZombossDeathRow` / `ZombossDeathColumn` 在当前 main 脚本没有读取，保留它们，不提供无效控件。
- 僵王可以在没有静态波次的关卡中自行生成敌人。修正旧校验器对此类原生关卡的误拦截，普通关卡的空波次检查仍保留。
- 空袭按 `FullPoint` 升序选择升级阶段。缺失、null、0 作为无限阈值；界面按实际顺序显示，保持原数组顺序，只有用户操作才修改数据。目标分数 0 表示不再额外要求积分，仍需满足关卡胜利条件。
- 编队名称可保留多语言扩展键或原生字符串。导入时已有的未知模组植物只警告，修改名称、重排编队不把旧异常升级为新错误；新增未知引用或额外复制同一坏引用仍报错。
- 飞船生命默认 20,000、护盾 10,000、三叶草速度 3、伤害 5,000、边界坐标 2.5。界面边界也用 1 起始坐标，例如显示 5.5 导出为 4.5。强制开启护盾优先于强制关闭，未选择强制策略则跟随游戏设置。
- 专项配置编辑使用保真对象更新；单独调整模块引用也不重建其他核心模块。与名称、棋盘编辑混用时仍保留原始对象及引用顺序。
