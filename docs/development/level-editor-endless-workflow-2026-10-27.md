# 关卡编辑器：原生无尽关卡创建与设置

2026-10-27，第五轮。延续游戏字体标题、Gardenest 编辑区和玻璃窗口。普通无尽关卡现在可以从完整原生模板创建，再直接修改生成器与无尽设置。

## 工作流

- 文件菜单提供「新建无尽关卡」，覆盖埃及、海盗、西部、未来、黑暗、沙滩、冰河、失落、复古、恐龙、摩登、功夫、天空 13 个世界。保留模板的舞台、环境、胜负条件、生成规则及其他依赖，只替换名称和描述。
- 波次区直接显示起始点数、每波 / 每层增量、动态种类、点数上限和候选 / 必选僵尸池。无尽模式不再展示本体会忽略的静态波次数量、巨浪间隔、插入波次或创建每日点数生成器入口。
- 无尽设置采用一个不遮罩工作区的侧面板，平铺进度世界、巨浪上限、音乐、初始 / 排除植物和规则链。植物可搜索添加，规则可以搜索添加、排序和删除；主点数生成器保留。删除引用不会删除原始对象。
- 搜索菜单按 Escape 只关闭菜单；窗口、菜单和控件沿用磨砂玻璃与键盘焦点。手机窗口约束内部宽度，长语言标签不会撑出窗口；高对比度 / 减少透明度时使用实色表面。
- 预览层数只保存在编辑器工程中，用于显示本层波数上界与第 1 / 10 / 最后一波点数，不写入游戏 JSON。实际波数仍由游戏随机决定。
- 修改支持撤销 / 重做、工程备份和刷新恢复。已有无尽小游戏可以编辑对应配置；本轮没有增加小游戏新建模板。

## 0.16.1 依据与边界

原生 `levelController.ts` / `PlayerProperties.ts` 及实际导入是行为依据：

- `IsDangerRoom` / `IsDangerRoomMiniGame` 选择对应模块，小游戏标记优先；本关同类配置采用最后一个对象。
- 正常无尽通过 `WorldSpecificDangerRoomProperties.WorldProp` 复用玩家的世界无尽进度。不能用任意字符串假装独立存档空间；界面在创建和设置时明确提醒共享进度。初始植物会加入已获得植物，移除配置不会清空既有植物。
- 正常进度选项仅取 13 个原生模板实际使用的配置，避开 PropertySheets 中类型标记不一致的遗留 Pirate 小游戏条目。已有小游戏采用其原生类型的 10 个世界选项，未知引用保持原值。
- 巨浪间隔固定 10。有效正数配置下，本层随机波数上界为 `10 * ceil(min(MaxFlagWave, floor / 4))`，默认正常 4、小游戏 2 个巨浪。
- 普通波基础点数为 `min(MaxPointPerWave, StartingPoints + (BasePointIncrementPerWave + BasePointIncrementPerLevel * floor) * waveIndex)`，waveIndex 从 0 起。巨浪在上限计算之后乘 2.5。缺失点数上限与显式 null / 0 的原生行为不同；预览保留该区别及原生数值转换语义。
- 规则目录仅提供 `readDangerroomDesigners` 实际处理的 28 类，按 RTID 命名空间解析本关或 LevelModules 对象。可以使用现有配置组合规则；规则内部的世界专用参数仍保留原数据，等待后续专项编辑器。
- `DangerRoomLevelIntroProperties` 是无参数原生标记，不再作为未支持配置告警。新产生的无效必需配置阻止导出，导入时已存在的异常只警告并保留。

使用 REA 对只读原版编译模块做了目录分析，父证据为 `ev_7ebe050c2b57000979712ca22191f9bcfddf04efad752f4f35c418a96502b746`。该语义图受单文件 20,000 节点上限约束，且没有包含全部依赖，不能单独作为运行正确性的证明；上述关键公式和分支另行核对原始编译代码，并进行下述运行验证。13 个模板原样摘自 0.16.1 导出的关卡资源，版本清单与官网维护版本绑定检查。
