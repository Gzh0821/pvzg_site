# 关卡编辑器：直接波次编排与多套卡组

2026-10-26，第二轮。用户明确优先改善波次编排。本轮延续 Gardenest / 新存档编辑器的青绿、薄荷和磨砂玻璃材质，调整实际操作结构，减少展开栏、重复表单和选中后再添加的往返。

## 交互变化

| 任务 | 当前操作 |
| --- | --- |
| 添加普通出怪 | 选行，点击素材即加入；行内直接修改数量和行，支持桌面跨行拖动及键盘 / 手机行选择 |
| 编排波次 | 横向波次条，当前波次旁直接复制、插入、移动和删除 |
| 编排事件 | 平铺执行列表负责选择和排序，旁侧属性区只显示当前对象；新增事件使用单层类型列表 |
| 动态难度 | 与事件共用旁侧属性区；素材和最近快捷键向当前动态池添加 |
| 事件僵尸池 | 选择风暴 / 地面等事件后，素材直接加入其僵尸池 |
| 卡组 | 单个供给方式选择器；固定、包含、排除、推荐、挑战分别直接选择编辑目标 |
| 多套推荐 / 挑战卡组 | 新建 / 删除 / 切换卡组，多语言名称、植物、领队、挑战奖励及挑战规则直接编辑 |
| 刷新恢复 | 额外保存当前行、事件属性和卡组目标；新建 / 导入会重置上下文，撤销新增卡组后仍显示已有卡组 |

普通波次编辑区没有 `details` 折叠栏。原始 JSON 和内部事件别名仅在高级模式显示。内部编排区域保持清楚实色控件，不叠加新的玻璃卡片；玻璃用于主面板、菜单和窗口。手机行内控件和行按钮至少 44px 高，波次操作集中于紧凑工具栏。

修正新建模板首次添加僵尸时内部 ID 与默认僵尸重复的问题：这会导致按 ID 拖动或删除时选错条目。旧模板工程恢复时重新分配重复 ID，保留每个条目及数量；导入关卡的比较基线不因此改写。

## 功能参考与兼容边界

[NLM](https://github.com/Osamah2004/nlm) 的直接波次操作和工作对象优先的布局是功能参考。[ELM 首页](https://docs.google.com/spreadsheets/d/1OeY3FcGfOSOCO6voz6VolK0lfSCX9ytsXbCdihECrk0/edit) 当前列出 10.3，并注明原项目停止更新；这里只参考表格式直接编辑，不把其 PvZ2 数据结构当作 Gardendless 格式标准。

0.16.1 格式与含义依据本地游戏原始 `levelController.ts` 和 `CardDeckDisplayer.ts` 编译模块、官方关卡以及原生文件入口：

- `CardDecks.Recommended` / `Challenging` 存在于 233 个官方关卡；`Leader` 为零基索引。
- 移除领队植物或它之前的植物时调整索引；新增空卡组和新产生的越界领队阻止导出。
- 5 个原版关卡已有越界领队；未修改植物结构时作为警告保留，不静默修复原版数据。
- `ChallengingLocked` 在本体里隐藏推荐卡组、仅显示挑战卡组，界面据此命名；`SuppressChallengingHugeWaveGems` 禁用挑战巨浪宝石。
- 推荐 / 挑战仅供玩家选卡模式消费，预设卡组模式不显示无效配置入口。改名、改植物时保留其他语言、卡组规则、未知扩展和原模块别名。
