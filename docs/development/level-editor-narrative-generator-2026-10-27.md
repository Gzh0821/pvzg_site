# 关卡编辑器：剧情与原生生成器

2026-10-27，用户恢复持续优化目标。本轮延续已有玻璃主面板，补充剧情与本体实际使用的生成器编辑。工具标题恢复 / 统一使用 `pvzgeFontEN`、`pvzgFont`，正文与表单继续使用原有易读字体。

## 交互变化

- 剧情使用独立工作区，直接选择首次 / 重玩、开场 / 结尾四个时机。可引用 488 个共享剧情、复制为本关独立剧情或新建；解除绑定保留对象，避免破坏其他引用。
- 本关剧情按执行顺序平铺角色、动作与台词，支持多语言、进入 / 退出、排序、复制与删除。共享剧情先预览，明确复制后才编辑。角色和动作以 0.16.1 NPC 为准，未知数据保留并提示。
- 波次区可打开原生生成器参数，直接编辑点数和僵尸池；素材库直接加入当前候选 / 必含池。普通关卡可确认后改为点数生成模式，替换静态编排支持撤销。波次数量与巨浪间隔复用现有波次区控制。
- 点数生成关卡的波次条显示实际点数预算，不再把运行时填充的空波次误报为没有僵尸。
- 剧情、生成器当前选择和工作区随工程保存，支持撤销 / 重做和刷新恢复。

## 0.16.1 依据与数据边界

只读检查本地原版 `assets/main/index.js`，聚焦 `NPC_Controller`、角色模块与 `levelController`。REA 对提取的 NPC 模块进行了摘要，主要含义仍通过原始实现和实际游戏导入复核。没有修改 `pvzge_build/src/public/`。

| 本体对象 / 行为 | 编辑器处理 |
| --- | --- |
| `NarrativeProperties` | 本地对象优先于共享剧情；四个 `LevelDefinition` 引用使用原生普通别名。复制时避开既有核心、波次与剧情别名 |
| 角色 | crazydave、winnie、zombossicon、crazydaveicon、winnieicon；动作按真实角色可用范围提供 |
| `LevelOfTheDayModuleProperties` | StartingPoints、PointIncrementPerWave、PlantfoodToSpawnCount、ZombiePool 可视化编辑 / 新建 |
| 原生点数公式 | 第 n 波使用 `StartingPoints + PointIncrementPerWave * (n - 1)`，巨浪乘 2.5 |
| `WavesPerFlag` | 读取模块后会被基础 WaveManager 的正 FlagWaveInterval 覆盖，因此使用基础巨浪间隔控件 |
| `DangerRoomJitteredWaveGenerator` | 编辑导入关卡的点数、每波 / 每层增量、点数上限、动态类型数量、候选与必含池及能量豆开关；尚未提供从普通关卡创建完整无尽配置 |
| 历史 `WaveGeneratorProperties` | 当前本体脚本没有此类或对应消费路径，作为历史未知对象保留，不把它包装成可用原生生成器 |

剧情 / 生成器单独编辑通过选择性导出，仅改目标字段 / 对象，保留外层扩展、对象顺序、其他语言、未识别字段和既有缺省情况。组合编辑继续使用现有完整序列化流程。原版已存在的无效生成器字段作为警告保留；新产生的无效参数或空候选池阻止导出。未知剧情动作不会被静默修复。
