# 关卡编辑器：直接棋盘编辑与行内目标

2026-10-27，第四轮。延续游戏字体标题、Gardenest 主面板和磨砂玻璃材质，重点减少棋盘 / 目标的操作往返。

## 工作流

- 普通目标直接以行编辑数值，移除内部目标标签、重复摘要和选中后才能编辑的检查器。
- 禁种区域、保护植物从基础页直接进入棋盘；创建空间目标后立即进入对应工具。
- 棋盘提供选择、摆放、轨道、矿车、瓷砖、潮水、木板、禁种、保护工具。空间工具选定后直接点格子，重复点击移除；潮水点击设置边界。
- 选择工具只查看格子，即使已选素材也不会误放。保护优先使用格子上的植物，也可使用已选植物素材。
- 桌面棋盘与当前工具属性并排；小屏上下排列。棋盘内部可横向移动，每个格子至少 44px，不让整页溢出。
- 轨道 / 矿车的精细行列输入与棋盘统一显示为 1 起始编号，导出保持本体 0 起始坐标。轨道范围、矿车样式、瓷砖分组与延迟、保护数量和植物列表仍可直接修改。
- 同类型有多组模块时提供一个选择器，默认不显示单项选择器。切换工具不创建空模块，首次点击才创建；支持撤销、重做、工程保存和刷新恢复。

## 格式保真

真实 App 回归发现并修正旧序列化器的附带修改：

- 保留原文件中的重复模块引用，不因修改其他字段而静默去重。同一棋盘对象被多次引用时只显示一个可编辑对象，同时保留引用次数。
- 只有实际修改铲草机、阳光供给、选卡方式或初始摆放时才更新相应引用，避免删除其他模块已有的引用。
- 静态波次快照和不支持对象可能共同保留一个源对象；按原始出现次数写入，避免重复输出，也保留原文件中真正的重复对象。
- 不再因未解析到对象的 SeedBank 引用而创建默认卡槽模块。
- 修正潮水含义：StartingWaveLocation 为从右侧淹没的列数，预览边界为 `9 - StartingWaveLocation`；点选第 7 列左边界写入 3，而不是 6。
- 新棋盘规则、目标和目标容器避开其他核心 / 不支持对象的别名。禁种点保留其他格子的扩展字段。
- 新增摆放数据的比较域可从旧工程原有完整草稿指纹计算，旧工程无需重新导入。
